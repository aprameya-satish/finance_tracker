# Finance iPhone app

On-device household tracker. No computer or FastAPI process is required.

The easiest install path with no Mac/PC is the **Safari home-screen app**:

**https://aprameya-satish.github.io/finance_tracker/**

Safari → Share → Add to Home Screen.

This Expo project is the same engine, useful if you later build a native binary with EAS/Xcode.

```bash
cd mobile
npm install
npx expo start
```
